YT MultiView

Settings

YouTube API key — needed for the search boxes. Without it you can still paste YouTube links or video IDs into any tile.

  1. Go to Google Cloud Console → YouTube Data API v3 and press Enable (create a free project if asked).
  2. Go to APIs & Services → Credentials → Create credentials → API key.
  3. Copy the key and paste it below. It's stored only on this device.

Skip amount — seconds jumped by the «/» buttons on each tile. Decimals allowed, e.g. 6.76.

Default loop length — every tile carries its own loop length, shown on its ⟳ button; long-press a tile's ⟳ to change just that tile. This value is what tiles start from. Tapping ⟳ loops the tile from that moment for its own length.
