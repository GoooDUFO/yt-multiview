AD-FREE

Settings

YouTube API key — needed for the search boxes. Without it you can still paste YouTube links or video IDs into any tile.

  1. Go to Google Cloud Console → YouTube Data API v3 and press Enable (create a free project if asked).
  2. Go to APIs & Services → Credentials → Create credentials → API key.
  3. Copy the key and paste it below. It's stored only on this device.

Plays videos through a public Invidious server instead of YouTube's player — no ads at all. Trade-offs: it relies on a volunteer-run server (if videos stop loading, turn this off or change the server below), and ⏸ All doesn't work in this mode — pause each video with its own controls. ▶ All restarts all tiles together from 0:00.

iOS normally allows sound from only one video. This mode fetches a separate audio track for each video from a public Piped/Invidious server and mixes them on this device, so all tiles can be heard at once — tap a tile's 🔊 to mute just that one. If no audio server responds, the tile falls back to the single-sound speaker toggle. Works in the normal YouTube player mode (not ad-free mode).
